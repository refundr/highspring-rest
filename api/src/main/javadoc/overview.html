Error-code summary (quick)

CodeMeaningSaved to api_error_log?
200 / 201 / 204SuccessNo
400Bad request (validation / bad JSON / empty cart)No
401Missing or invalid sessionNo
403Authenticated but not allowed (e.g. non-admin)No
404Unknown path or missing entityNo
405Method not allowedNo
500Unexpected server errorYes + email
